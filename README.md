<h1>Calculator on Python</h1>
<p>This application is a calculator written on Python language. It supports not only binary operations but works as a calculator in your smartphone. Moreover it supports float numbers. In project I used Kivy module to create a UI of application.</p>
<h3>Operators of calculator</h3>
<ul>
  <li>Plus (+)</li>
  <li>Minus (-)</li>
  <li>Multiplication (*)</li>
  <li>Equal (=)</li>
  <li>Point to float numbers (.)</li>
</ul>
